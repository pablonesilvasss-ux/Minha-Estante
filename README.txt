MINHA ESTANTE — PROTÓTIPO WEB PARA ANDROID

O que inclui:
- Interface minimalista preta e amarelo girassol.
- Abas Em leitura, Minha Estante e Já lidos.
- Importação e leitura de PDFs, capa criada a partir da primeira página quando possível.
- Pesquisa por título e autor.
- Mover livros entre abas, editar informações e excluir.
- Progresso de leitura salvo localmente.
- Modo escuro/claro.
- Preferência de apelido, sem conta: o app usa o apelido na saudação inicial.
- Controles de visualização do PDF e opções de fonte.

COMO TESTAR
Abra index.html num navegador moderno. Para a leitura de PDF, a biblioteca PDF.js é carregada de uma CDN, então é necessária conexão com a internet na primeira utilização.

IMPORTANTE
Este pacote contém o protótipo web, não um APK Android compilado. Para produzir um APK instalável é necessário empacotar/compilar o projeto com ferramentas Android (por exemplo, Android Studio/Gradle e uma integração WebView ou Capacitor). O protótipo armazena dados localmente no navegador/dispositivo; limpar os dados do navegador pode apagar a biblioteca.
